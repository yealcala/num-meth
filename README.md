## Dependencies

This is a SageMath module. You will need to install and use SageMath 10.8 or newer for this package to work.

## Installing

Open a terminal. You may consider having a virtual environment in your project's root,

```bash
    python3 --system-site-packages -m venv .venv
```

If using **Linux**, you may want to source it

```bash
    source .venv/bin/activate
```

While in **Windows**,

```bash
    .venv\Scripts\activate
```

Finally, you may install the package in your virtual environment using `pip`:

```bash
    pip install num-meth
```
